# Design translation

An approved portable reference-product handoff was reviewed before this
receiving Project existed. Its design proof `online-sourdough-skills-atlas-r4`
passed desktop/mobile walkthrough, focus, reduced-motion, state, and
source-safety checks. The externally retained handoff is input evidence; it is
not included here or required at runtime.

The r2 owner revision additionally used an externally retained numbered
reference screenshot set (`01`–`05` and `07`–`18`) as direct structural
evidence. It informed whitespace, density, hierarchy, and interaction shape
only; neither those images nor their source location is included or shipped.

This implementation carries those resolved decisions into maintainable
components and CSS:

- warm paper `#f8f2e8`, paper surface `#fffaf1`, brown rail/action `#2b1b12`,
  walnut accent `#b86f36`, blue focus `#2b6f98`, and restrained graph tones;
- local Geist Sans, Geist Mono, and Geist Pixel font files under
  `public/fonts/`, with Pixel reserved for the wordmark and one display
  emphasis;
- a slim light Graph/Library/Usage tab bar and narrow light taxonomy rail;
- a dominant calm graph canvas with five softly tinted category clusters,
  real skill nodes, explicitly decorative density satellites, faint
  cross-cluster links, selection, filtering, and a readable preview;
- a dense three-region library with persistent detail/editor pane, a centered
  ranked usage/quiet-skills surface, and a global Ask panel;
- a minimal centered five-page onboarding sequence with restrained progress,
  original CSS diagrams, and responsive drawer/stack behavior;
- readable sentence-case controls, source-path labels, explicit public/private
  text, visible focus, reduced motion, and no hover-only meaning.

The receiving build intentionally uses Online Sourdough identity, original
copy, public-safe preview records, and original CSS diagrams. It does not copy
the reference product's brand, logo, prose, icons, screens, recorded-media
frames, likenesses, private material, proprietary assets, or long skill
passages, and it makes no affiliation claim.
